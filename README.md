## ✨ Features

- **Modern UI/UX**: Premium aesthetic with dark/light mode compatibility, a striking red and black color scheme, and glassmorphism elements.
- **Scroll Animations**: Smooth, staggered entrance animations powered by the `IntersectionObserver` API.
- **Fully Responsive**: Fluid grid layouts that look perfectly scaled on desktop, tablet, and mobile devices.
- **Interactive Navigation**: Mobile pop-up menu with dynamic hamburger animations and a sleek sticky header.
- **Integrated Contact & Location**: Interactive Google Maps embedding and one-click social connection links (WhatsApp, Instagram, Justdial).

## 🛠️ Tech Stack

- **HTML5**: Semantic, SEO-friendly markup.
- **CSS3 (Vanilla)**: Custom design system using CSS variables, Flexbox, Grid, and advanced hover/transition effects. *(No bulky external CSS frameworks)*
- **JavaScript (Vanilla)**: Lightweight DOM manipulation for navigation menus and scroll-based intersection observers.

## 🚀 Installation & Usage

Since this is a static website, no complex build tools, package managers, or terminal commands are required!

1. **Get the Code**: Download the folder to your local machine.
2. **Open the Project**: Simply double-click `index.html` to open it in any modern web browser (Chrome, Firefox, Safari).
3. **Local Development (Optional)**: If you plan on doing heavy editing, use a local server like [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code to see your changes instantly upon saving.

## 🎨 Customization Guide

- **Brand Colors**: The entire color scheme is controlled via CSS variables at the top of `style.css` (e.g., `--theme-red`, `--bg-primary`, `--bg-secondary`). Change them once to update the whole site.
- **Images**: Search for `<img src="...">` placeholders in the HTML files to easily swap in your own project photos and logos.
- **Social Links**: You can update your WhatsApp number or social URLs directly in `contact.html`.
